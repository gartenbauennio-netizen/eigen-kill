# Meine Skills

Hier stehen alle Skills, die ich nutze. Pro Skill: wofür er da ist.

## Dokumente und Dateien

**docx**
Word-Dokumente erstellen, lesen und bearbeiten.

**pdf**
PDFs erstellen, lesen, zusammenfügen oder ausfüllen.

**pptx**
PowerPoint-Präsentationen erstellen und bearbeiten.

**xlsx**
Excel-Tabellen erstellen und bearbeiten.

**excel-generator**
Schöne, übersichtliche Excel-Tabellen für Daten.

**typst-pdf-maker**
Hochwertige PDFs mit Typst, zum Beispiel Berichte oder Lebensläufe.

**file-reading**
Hochgeladene Dateien richtig einlesen.

**pdf-reading**
Inhalte aus PDFs herauslesen.
